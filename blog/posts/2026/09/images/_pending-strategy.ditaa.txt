做法 A（错误）：未超时的队首塞回队尾
+----------+----------+----------+----------+
|  P 老元素   |    X     |    Y     |    Z     |
|   未超时    |          |          |          |
+----------+----------+----------+----------+
塞回后：
+----------+----------+----------+----------+
|    X     |    Y     |    Z     |  P 老元素   |
|          |          |          |   未超时    |
+----------+----------+----------+----------+
FIFO 序被破坏：P 沉底，最老的元素被晾着
下一轮检查队首 X——X 比所有元素都年轻，
队首永远不超时，P 永远轮不到 → 只看队首的前提崩塌

做法 B（正确）：P 不入队，记在 pending 字段持有
队列：      +----------+----------+----------+
         |    X     |    Y     |    Z     |
         +----------+----------+----------+
pending：P（全队列最老的未过期元素）
下一轮 Cleanup 先查 pending：未超时 → 继续持有，队列原封不动
                    超时/完成/消失 → 释放 pending，接着扫队列

不变量：每轮结束时，pending 持有的 = 全队列最老的未过期元素
