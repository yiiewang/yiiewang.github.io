# 结构化读书笔记写作框架

> 读书笔记不是复述原文，而是用框架将原文重新"翻译"一遍——让读者看到原文自己没看到的结构。

## 背景

写读书笔记的常见困境：摘抄太多像抄书，感想太散像日记，结构太平像流水账。一篇好的读书笔记需要同时做到三点：（1）忠实传达原文的核心观点，（2）有自己的解读框架，（3）让读者读完"有所得"。

本文提炼自博客 [读毛选《我们的经济政策》](../../../blog/posts/2026/07/04.md) 的写作实践，总结了一套可复用的结构化写作框架。

## 核心技巧

### 1. 对比手法制造冲击

**技巧**：在正式展开分析前，先用一组强烈对比让读者"看到差距"。

原文用一个段落的国统区惨状（地主囤粮、官僚敛财、老百姓吃不上饭）对比苏区的局面（土地分下去、合作社搞起来、贸易路线撕开口子）。对比完成后点出核心结论：**"经济好不好，不只看资源，更看组织。"**

**使用要点**：
- 对比的两端要有可比性（都是"当时中国的经济状况"），否则像在讲两件事
- 对比的目的是引出一个**洞察**，不是为了对比而对比
- 篇幅控制在一段，太长就变成了铺陈而非对比

### 2. 框架化拆解：先定纲，再举目

**技巧**：找到一个超级框架（通常是二元对立的经典概念），用这个框架重新组织原文内容。

这篇用的是"战略 vs 战术"框架：
- **战略层（原则）**：方向性决策 → "尽一切可能把事情办成"
- **战术层（中心）**：资源投哪里 → 农业、工业、对外贸易、合作社

框架的好处是读者不需要自己梳理原文逻辑，你帮他把结构搭好了。纲举目张。

**选择框架的原则**：
- 框架要足够通用（战略/战术、道/术、what/why/how、输入/处理/输出），让读者一看到就能理解
- 框架是用来"套"原文的，不是用来"改写"原文的——原文内容必须原封不动归位到框架的对应位置

### 3. 递进式结构：像搭积木一样组织内容

**技巧**：从宏观到微观逐层展开，每一层是下一层的底座。

本文的递进层次：
```
对比铺垫 → 原则（战略）→ 中心（战术）→ 落地的颗粒度 → 内部防线 → 总结升华
```

关键不是层数多，而是**每层之间有明确的递进关系**——读者能感受到"先有方向，后有执行，执行完了还要防范风险"的自然逻辑。

**检验方法**：打乱任意两层的顺序，看是否别扭。如果随便调换也无所谓，说明层次之间没有真正的递进。

### 4. 引用原文的时机

**技巧**：引用放在论证之后，用原文收束论点，而非用原文代替论证。

本文只在结尾处引用了一句毛泽东原文：

> 事情是非常明白的，只有我们战胜了帝国主义和国民党，只有我们有计划地、有组织地实行了经济建设工作，才能挽救全国人民于空前的浩劫。

引用前已经完成了"为什么干这些"的完整论证，引用是增强力量，不是填补空白。

**⚠️ 常见误区**：大段引用原文 + 一句话点评。这叫摘抄，不叫读书笔记。

### 5. Admonition 标注关键转折

**技巧**：在文章的逻辑转折处用视觉提示（如 MkDocs 的 `!!! tip`）帮助读者定位。

本文用两个 `!!! tip` 标注了：
1. **第一个转折**：对比结束，点出对比的力量（"对比本身就是力量"）
2. **第二个转折**：战略转向战术（"先把纲立住，再谈目"）

**使用要点**：
- 一篇 2000-3000 字的文章用 2-3 个提示块即可，多了反而削弱效果
- 提示块的内容要给出**洞察**，不是重复前文

### 6. 现代转化：去语境化

**技巧**：把原文的历史语境剥离，保留方法论内核，转化为当代可用的框架。

本文通篇用"苏区"的实践讲方法，但最后一段明确做了转化：

> 那些做事的方法——先定原则再定中心、分清主次、落到细节、防范内部风险——这些框架放到今天任何一个场景里，依然能用。

并在推荐指数中进一步具体化："放在创业、项目管理、甚至个人奋斗里都有启发。"

**核心原则**：不要停留在"这文章写了什么"，要回答"这文章的方法现在还能怎么用"。

### 7. 推荐指数收尾

**技巧**：用星级 + 一句话理由收束全文，给出可操作的阅读建议。

本文用 ⭐⭐⭐⭐⭐ + "如果只读一篇毛选里关于经济的内容，这篇足够" 收尾，既给结论，又给行动建议（"读这篇"）。

## 完整写作流程

```
┌──────────────┐
│ 1. 读原文     │ → 理解核心主张和论证逻辑
└──────┬───────┘
       ▼
┌──────────────┐
│ 2. 找框架     │ → 选一个超级框架（战略/战术、道/术、what/why/how）
└──────┬───────┘
       ▼
┌──────────────┐
│ 3. 定开头     │ → 设计对比，制造冲击
└──────┬───────┘
       ▼
┌──────────────┐
│ 4. 搭结构     │ → 按递进层次排列：原则→中心→落地→防线→升华
└──────┬───────┘
       ▼
┌──────────────┐
│ 5. 填内容     │ → 原文内容归位到框架的对应位置
└──────┬───────┘
       ▼
┌──────────────┐
│ 6. 加提示     │ → 在转折点放 2-3 个 admonition
└──────┬───────┘
       ▼
┌──────────────┐
│ 7. 做转化     │ → 去历史语境，方法论通用化
└──────┬───────┘
       ▼
┌──────────────┐
│ 8. 收尾       │ → 推荐指数 + 行动建议
└──────────────┘
```

## 注意事项

- ⚠️ 框架是为内容服务的，不要为了"框架漂亮"而扭曲原文意思
- ⚠️ 递进结构的关键是层与层之间的**逻辑关系**，不是数量多
- ⚠️ 对比两端的篇幅要均衡，避免一面渲染过多而另一面一笔带过
- ✅ 一个框架反复用：一旦找到适合某类读书笔记的框架，可以在同类型文章中持续使用，形成个人风格
- ✅ 每篇文章至少有一个"读者能带走"的方法论（本文是"先定原则再定中心"）
