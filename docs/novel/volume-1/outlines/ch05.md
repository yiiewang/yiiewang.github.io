# 第五章《自家的米缸》分幕归档

> 本章正文已入库：[第五章 自家的米缸](../chapter-05/)。
> 本页保存动笔前的施工图，并附成稿校记；工作流说明与下一章拆幕见 [剧情大纲](../../bible/plot-outline/)。

时间：后至元四年（1338），ch04 后一二日（借米第十天上下，时间连续）。背景：秋收还差十来日。承载知识点：家庭收支——一家人的进出远比想象的复杂；别只替别人解决问题，忽略自家处境。双推进：情节（立账 → 算总账撞税 → 集上买盐 → 灶间分工）+ 人物关系（重八与娘从分歧走向分工）+ 主角认知（数字和娘的心算各有各的准；账能算出省来算不出挣来）。

## 施工图

| 拍 | 内容 | 功能 |
|---|---|---|
| 起 · 缸里的刻痕 | 借米第十天：娘隔几天用升子挖一升看缸底；重八提出给自家立账——娘不识字但会心算 | 从「别人家的账」回到自家：立账 |
| 承 · 账的第一次用 | 娘的心算三天笔笔不差；重八合总账——进项只有秋后卖新谷，出项立着秋税与盐油鞋药；「进项在秋后，出项在眼前」 | 认知落点一：家庭收支的复杂；站着算与坐在灶间算不是一种算法 |
| 转 · 盐罐见了底 | 盐罐见底，重八头回攥钱上集：四摊比价、压价被「爱买不买」顶回、点钱复点、搭头两粒盐；「盐价是行里定死的」 | 眼前出项具体化；集市初体验（粮行大秤、出街的粮车——为村庄之外阶段留门） |
| 合 · 灶间的新政 | 省法一揽子：灯芯、盐、鞋过；「改两顿」被娘一口否死（省下的钱不够抓药，省下的饭误的是人）；娘划分工——「吃穿的事娘管，账上的数你盯着」 | 娘与重八从分歧（ch3「我就说说」）走到分工：家庭内部第一次协作 |
| 结 · 房梁上的碎米袋 | 税钱问爹：折色要调、等里长告示；「账能算出省来，算不出挣来」；房梁挂上娘的碎米袋（姥姥传下的法子），重八自己缝第二只袋挂旁边（卖猪草的钱）；三代人三样家伙什守一个东西 | 双推进收束：家庭协作立住；税差仍悬（引向秋后卖粮线）；章末「账本在长，米缸在浅——好在都有人看着了」轻收 |

**与 ch04 的差异化**：ch4 是「想动而不能动」，ch5 是「能动且要动」——但战场从别家回到自家；娘从「顶回他的人」变成「跟他分工的人」，人物关系实质推进。

## 成稿校记（施工图 → 成稿）

- **起幕**：娘看缸的方法写成完整的一套动作（升子探底、看露多少、袖子抹升）；「刘家的账他算得头头是道，自家的呢？」——ch3-04 的「替别人算」与本章「替自家算」接上；娘的「我不识字」不是拒绝，是命题——立账先解决这个，重八听懂了。
- **承幕**：新增「娘的账是活的」三层——跟锅走、跟天走、跟人的力气走（他歇着在家，米就少下半升）；重八在板边加小字「收支要问娘——娘的数，比我的准」：数字与心算的互认。总账撞税：出项中「药」是他头一回没法动的出项。
- **转幕**：集市扩写——赶鹅娃的两次照面（去时扬下巴、回时各走岔路）；粮行大秤与比人高的麻袋（粮车出街与「粮行的车一天比一天多」对上——ch24 粮价线与第四阶段的门）；「点清楚，您好，我也好」+ 搭头两粒盐——重八的交易初体验有礼有节。娘验盐「我让你称的盐，我知道多少钱」——娘的账连集上的事都罩着。
- **合幕**：省法讨论保留「一口都不省」的娘之杠；分工令是本章戏眼——娘接走吃穿、交出账目，还给了期限责任（「提前一个月告诉娘，别等到缸底才吱声」）。
- **结幕**：猪草袋扩成一整场——徐达的捆草手艺（我娘教的，捆柴同理）、汤和「四家合着打合着卖」的起意（重八「记在心里的账上」——ch7-12 协作线的种子）；姥姥-娘-重八三代三样家伙什（碎米袋-麻绳结-炭条字）；爹磨镰念账、「账能算出省来，算不出挣来」与娘的「丰年攒不下，歉年就见底」——父母的两句收在同一个夜里。
