# 第四章《一碗谢礼》分幕归档

> 本章正文已入库：[第四章 一碗谢礼](../chapter-04/)。
> 本页保存动笔前的施工图，并附成稿校记；工作流说明与下一章拆幕见 [剧情大纲](../../bible/plot-outline/)。

时间：后至元四年（1338），ch03 后一二日（借米第七天上下，时间连续）。背景：豆糕道谢的第二天起，流言仍在变形。承载知识点：误会发酵与「资格」——感激与索还都是别人的，主角没有资格替任何一方决定；不能仅凭表面判断人。双推进：情节（发酵 → 催还口风 → 真相在娃群里回流）+ 人物关系（四伙伴第一次在同一件事上判断分歧）+ 主角认知（解释的失败 →「她托你了吗」→ 不推，让话自己走）。

## 施工图

| 拍 | 内容 | 功能 |
|---|---|---|
| 起 · 井台的风 | 豆糕第二日，流言两头变形：「装穷借粮转眼蒸糕」与「田五嫂的利钱挣得亏心」双向伤人；田五嫂跟中人陈老爹放了口风：秋后的工不如折成米，早还早清；刘二嫂从赵家媳妇嘴里听到「嫌你家装穷」，蒙头在家两天 | 误会发酵实质化：催还的口风出现，两头的伤都在加深 |
| 承 · 她又没托你 | 重八坐不住，先寻放鸭的陈老爹讨主意——「你想替她说？她托你了吗？」；他仍不死心，寻着由头跟田五嫂提「刘婶子家野菜一天三筛」，被「糕是哪来的？」堵死；田五嫂的委屈正面露头：半斗是省下自家娃的口粮借的，「她家要不难，你说婶子这算什么？」 | 解释的失败；田五嫂要的不是粮，是个「我做得对」的确认——糕恰恰剥夺了这个 |
| 转 · 坡上的四张嘴 | 四娃第一次在同一件事上判断分歧：汤和「借了粮记人情，送糕天经地义」；周德兴「一盆糕两头都能看——你的野菜，也只有你信」；徐达「先弄清楚」——他真去找了二丫（ch3 捡篮子的前情），带回收获：糕是娘夜里泡豆磨到鸡叫、掺新借的米，全家一块没吃，二丫说到一半哭了 | 三伙伴立场立住；徐达把糕之内幕问了出来——「先调查」落到实处 |
| 合 · 真相的分量 | 真相到手，重八反而更不能说：说破，撕的是刘婶子拼力遮的体面；不说，田婶子的心继续悬着——每个答案都要拿别人的东西去付。感激是刘婶子的，疑虑是田婶子的，两头都不姓朱——他没有资格替任何一方决定该不该感激、该不该索还 | 本章认知落点（规划原文落地） |
| 结 · 让它自己走 | 重八头一回决定什么都不做。场边上，二丫哭着跟田家小丫说漏了嘴——「我娘磨豆磨到鸡叫」；话还没进大人耳朵，但已经在飘。田家小丫把兜里的炒豆全倒给了二丫——大人们的结还结着，娃们先开了 | 钩子：不推，让话自己走；误会消解的种子留给后续章 |

**与 ch03 的差异化**：ch3 是「看」（观察后果），ch4 是「动」（试图解释 → 失败 → 学会不动）——主角从看见，到想管，到明白管不了、管不得。

## 成稿校记（施工图 → 成稿）

- **起幕**：井台三回流言逐回升级，第三回写成重八亲耳所听的完整对话（「没准数的事，说的人最欢喜」——流言的机制由人物自己说出）；田五嫂的口风经汤和之娘—汤和转述（闲话的管道感）；二丫井台打水「舀满又添半瓢」——娃在井台多站一会儿的委屈。
- **承幕**：陈老爹一场是本章的定音——「她托你了吗」之前先有「跟谁说」的三连问（重八一个一个地哑）；重八不死心去田家，带着「学了乖」的由头（空手说不成话）；田五嫂的掏心不写成控诉——「借出去的是善事，秋后能收回来，善事就还是善事」：她要的确认第一次说破；末了她不赶他，「韭菜我收了」——她不迁怒。
- **转幕**：重八第一次把事「摊开」给伙伴（「摊开了，事就轻了些」——从烂在心里到摊在中间，伙伴关系的价值第一次被他自己说出）；周德兴的刀先立理后扎人（「觉得，是拿不出手的」）；汤和「我去说道说道」被拦——他的「动」与重八的「不动」成对照；徐达的报告写成「念一样小心捧回来的东西」，一句一段，不许煽情。
- **合幕**：「谣言止于智者」的现代信条在门槛上破灭（「村里没有智者，只有过日子的人」）；「每个办法都要拿别人的东西去付」——说破拿的是刘婶子的脸，不说拿的是田婶子的心；娘的半块糠饼接住这一拍（收在吃食上，不收在道理上）。
- **结幕**：种子落地写成远景——重八「远远看见，听不见」，只看见一个大点的丫头哭着、一个小点的丫头往她手里倒了什么；田家小丫倒炒豆是娃们的和解先于大人；「路过刘家院墙把这一停咽回去」是「不动」的具体动作。三缕炊烟收尾：「哪家的烟底下，都是要过日子的。」
