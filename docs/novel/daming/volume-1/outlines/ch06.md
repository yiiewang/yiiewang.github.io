# 第六章《渠边的争论》分幕归档

> 本章正文已入库：[第六章 渠边的争论](../chapter-06/)。工作流说明与下一章拆幕见 [剧情大纲](../../bible/plot-outline/)。

时间：后至元四年（1338），ch05 后数日（借米半个月上下），紧接（时间连续）。承载知识点：公共事务与集体协作——出工成本与受益不均；分段认段、透明画杠、当众按手印。双推进：情节（渠漏→出工之争→分段认段→修成但争议留）+ 人物关系（汤和替冯三挖两锄——嘴硬心软）+ 主角认知（事情做成了，争议还在——不满意比失败更难消化）。

## 施工图（与成稿一致性高，不另列校记）

| 拍 | 戏核 |
|---|---|
| 起 · 渠漏了 | 秋收前放水渠中段裂口，下游等水、上游不急、中段遭淹各说各理 |
| 承 · 出工之争 | 按户出、按亩出，各家有各家的委屈；十家十本账对不上 |
| 转 · 分段认段 | 炭板画渠分三段、按田认段、出工出料、当众按手印——透明让议论止步 |
| 合 · 修成了 | 修渠当日冯三缺席→周德兴提醒冯三去年腰伤→汤和替挖两锄头；渠道通但上游两家觉得出多了 |
| 结 · 渠水到田 | 五家谢了，两家躲了；娘：「让人人满意的事，一件也没有」 |
