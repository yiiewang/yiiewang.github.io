# 第一卷 · 凤阳少年

> **核心主题**：先活下来，再看清人心。
>
> 这一卷不急于改变天下——先把童年写得有生活气息、有冲突、有情感、有真实的成长。

## 基本信息

| 项 | 设定 |
|---|---|
| 卷名 | 凤阳少年 |
| 规模 | 以 70 章为目标（60-80 可调），先落实前 12 章因果关系 |
| 时间 | 元后至元四年（1338）起；收束走向按史实时间线确定（详见 [创作圣经](../bible/worldbuilding/)） |
| 地点 | 濠州钟离县乡村 |
| 主线 | 从柴火、农具、一斗粮的小事，长出思考方式与最早的信任 |

## 卷目标

1. 建立朱重八幼年的生活环境与家庭处境。
2. 让未来的伙伴自然登场。
3. 通过小事件表现主角的现代思维，并让想法被现实检验。
4. 展现贫困社会中人们的实际困难。
5. 逐步建立人物关系和早期信任。
6. 为离开乡村、进入寺庙和漂泊生活铺垫。

## 卷末去向

本卷将收在灾年与家庭危机（对齐至正四年旱蝗大饥疫的史实锚点）——主角离开乡村，进入皇觉寺。此后是第二阶段「寺庙与漂泊」：观察社会，认识结构性问题。
