# 创作圣经 · 总览

> **一句话定位**：这里管三件事——世界是什么样（世界观）、有谁在（人物档案）、事情怎么发展（剧情大纲）；外加一条不可越的底线（写作规范）。

写任何一章之前，先过一遍这里的 checklist；写完一章，把人物状态与时间登记回对应页面。圣经与正文冲突时，以圣经为准修圣经，或以圣经为准修正文——不允许悄悄吃书。

## 动笔前 checklist

- [ ] **时间线**：本章发生在何时？距上一章多久？主角几岁？——查 [世界观与历史框架](worldbuilding/#时间线登记表)
- [ ] **人物状态**：每个出场人物上一章结束时在哪、与主角关系如何？——查 [人物档案](characters/#人物状态登记表)
- [ ] **知识点**：本章承载哪个「现代知识落地」案例？是否与已用过的重复？——查 [剧情大纲](plot-outline/#章节进度)
- [ ] **红线**：十条红线逐条过——查 [写作规范](style-guide/#十条红线)
- [ ] **悬念**：章末留了什么钩子？写完登记回剧情大纲

## 变更规则

1. 设定变更（改年份、改人物设定、调大纲）必须登记在对应页面的「变更记录」小节，注明原因与日期。
2. 已入库的章节正文不回头大改；发现设定冲突时优先记录，后续章节规避。
3. 史实与虚构冲突时：优先保证整体时间线合理，并明确标注哪部分属于艺术加工——不冒称史实。
