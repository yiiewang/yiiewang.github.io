# 写作规范

## 叙事风格（五条）

1. 通俗、流畅的中文网络小说风格；有历史厚重感，但**不堆砌文言词汇**。
2. 有爽点，但不采用无条件碾压式开挂。
3. 多写动作、对话、场景和具体矛盾，少用空泛议论。
4. 可以有幽默感——童年伙伴要像真正的孩子。
5. 重大历史事件要有铺垫，不突然发生。

### 语体细则（以 ch1 原文为基准，ch3+ 遵循）

| 项 | 规范 |
|---|---|
| 对话引号 | 弯引号“...”，不用直角引号「」 |
| 对话标签 | 能省则省：优先无标签的对话轮替；必要标签用后置式（“...”徐达问）或独立动作段引导；少用「“X”他说“Y”」长嵌套 |
| 方言拟态 | 不用「俺 / 咋 / 啥 / 门儿清」类土话；对话用干净白话；儿化词仅保留「这儿 / 那儿」等通用词 |
| 时间口语 | 「明日 / 昨日」不用「明儿 / 昨儿」 |
| 比喻 | 克制，每章至多两三处，白描优先（ch1 近乎无比喻） |
| 章首 | 不用引用块；以时间地点叙述句 + 环境描写开篇（如 ch1「后至元四年，濠州，钟离县。春寒尚未退尽……」） |
| 场景分隔 | 正文内用「※」单独成段；**禁用** `***`（Markdown 分隔线） |
| 正文纯净 | 正文不含**任何** Markdown 语法（含 `*` 粗体、`***` 分隔线、链接与标签）——强调用孤段短句实现；以正文末句收尾；章节切换由侧边目录与卷首卡片承担（frontmatter 与页面 H1 为站点骨架，不在其列） |
| 议论段 | 一句一段，克制平实；警句密度低而稳（参照 ch1「有些话不必说得太满」式收束） |
| 段落 | 单句成段为主，短段，长短交错出节奏 |
| 章节篇幅 | 每章正文净字数约 **5000 字**（4500—5500 内浮动）；密度优先——不为凑字注水，也不硬删该有的过程肌理；交稿前过一遍字数 |

## 节奏与轻重缓急

全书不能都是爽点——轻重缓急是长篇的命脉。

1. **章型四分**：高潮章（大事件、组织全速运转）/ 挫折章（吃瘪、代价）/ 缓章（日常、观察、人情慢水流）/ 过渡章（铺垫蓄势）。
2. **曲线规则**：高潮章之后必须回落——「轻 → 中 → 重 → 回落 → 蓄势 → 再起」的呼吸循环；**连续两章高潮禁止**。
3. **爽点配额**：每章至多一个真爽点；爽点要靠前面的压抑与后面的回落衬托。
4. **一个事件可以写好几章**：不搞「舞台剧」式的章内完整事件弧——事件拆开慢写，每章只走一段路；冲突不要求章内闭环；过程肌理（干活、闲话、村景、心理流）本身是内容。
5. **吃瘪优先**：遇事先「试」，试了未必成——能成的也要打折。
6. **结构性问题不许提前爽掉**：属于后期阶段的命题（市场与官府勾连、结构性盘剥），前期只写「看见 → 试 → 不成 → 长眼」，不写扳倒。
7. **结尾不报幕**：不每章「点题收束」；母题句式（「天下……有数」）只在事件段落的关键章出现，其余章节悬念轻收或生活流收。

## 每章双推进（硬规则）

每章必须同时推进至少两项：**情节、人物关系、主角认知、历史背景**。例：写借米后果的章，同时完成一次重八与母亲的真实分歧；写收成的章，同时改变主角对公平的理解；写外部消息的章，同时让主角学会区分传闻与可核实的信息。读者每看几章，都要觉得人物和故事向前走了一步。

## 时间线规则（连续推进）

1. **默认连续**：章与章间隔数小时至数日；每章开头交代距上一章过了多久、空档里有什么变化（过渡桥）。
2. **跳跃是例外**，仅限三类：季节段跨越、跨年、卷际。每个跳跃必须在前章末尾或后章开头有交代（蒙太奇补叙，或重复场景做时间加速）。
3. **跨年用时间加速**：以周期性重复场景推进（如每年秋收唱账——账册一年比一年厚、人物一年比一年高），不用「一晃数年」式空跳。

## 知识融入：先问题，再办法，后检验

**三步律**：先有问题 → 再有办法 → 办法经效果检验 → 效果可能失败。

知识不进对话说教，只进实际问题。主角不长篇大论讲授现代政治学、经济学、管理学。

| 场景 | 承载知识点 | 状态 |
|---|---|---|
| 分柴火 | 分工、公平、协商 | :material-check: 已用（ch01） |
| 借粮 | 信用、风险、契约 | ch02 使用中 |
| 修农具 | 成本、资源整合 | :material-check: 已用（ch01） |
| 农忙 | 组织、激励、责任分配 | 章节池候选 |
| 粮食清点 | 账目、库存、信息准确性 | 待用 |

| 地方治理 | 税赋、土地、基层执行、监督 | 待用（第四阶段） |

## 历史与现实约束（六条）

1. 尊重元末社会的基本历史背景。
2. 真实历史人物：尽量核对生平、年龄、关系与重要事件；史料不确定处可合理虚构，**不冒称史实**。
3. 现代知识需要古代的材料、工艺、人力与制度条件才能落地——不解释可行性就不许落地。
4. 不把现代概念直接套进元末。
5. 度量衡、粮价等一律用**生存尺度**表达（「够一家吃几天」），不写精确数字。
6. 不把幼年主角写成早熟到不像孩子。

## 人物塑造原则

每个角色都要有：

- 自己的利益和目标。
- 性格上的长处与短处。
- 与主角相处时的真实情绪。
- 随年龄、身份、经历发生的变化。
- 与主角意见不合甚至冲突的理由。

主角需要学会用人，也需要学会**看错人、修正判断**。

## 十条红线

每章交付前逐条对照，越一条即返工：

1. 不一开篇就让主角谈论改革整个大明。
2. 不让幼年伙伴拥有不符合年龄的军事和政治能力。
3. 不让每个角色都立刻崇拜主角。
4. 不把未来历史成就当作当前人物能力的证明。
5. 不让主角只靠现代知识解决所有问题。
6. 不用大段说教代替真实冲突。
7. 不频繁重复分工、记账、公平同一套道理——每次都要有新问题与人物发展。
8. 不让历史事件、人物年龄和人物关系明显错乱。
9. 不为爽感随意改变已建立的时间线和人物设定。
10. 不把制度改革写成毫无代价的万能方案——每项改革都有成本、阻力、受益者与受损者。

## 每章交付自检清单

- [ ] 延续上一章的时间线、语气与人物状态
- [ ] 本章矛盾、人物行动、情节转折已在动笔前设计
- [ ] 承载一个未重复的知识点，且经三步律检验（可能失败）
- [ ] 其他孩子有自己的判断、反对意见和行动
- [ ] 章末留有合理悬念，已登记回 [剧情大纲](plot-outline/)
- [ ] 既推动故事，也推动人物成长
- [ ] 不确定史实已核对或标注不确定性，不编造
- [ ] 十条红线全过
