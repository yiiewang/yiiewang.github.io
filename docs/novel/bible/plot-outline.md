# 剧情大纲

## 全书四阶段

| 阶段 | 范围 | 核心命题 | 写作禁区 |
|---|---|---|---|
| 一 · 凤阳乡村 | 生存与识人 | 让读者相信：一个孩子能从日常生活中长出自己的思考方式 | 不急于改变天下，先写生活气息与真实成长 |
| 二 · 寺庙与漂泊 | 观察社会 | 善意和聪明无法单独解决结构性问题 | 以生存、观察为主，不早进宏大治国演讲 |
| 三 · 从军与崛起 | 组织与战争 | 战争不靠预知历史取胜——情报、天气、地形、补给、士气、误判、偶然都要起作用 | 不重复同一套组织道理，让班底在岗位中分化成长 |
| 四 · 建国与治理 | 从个人能力到制度 | 终极问题：他能否建立一套比个人更稳定、有效的治理机制 | 改革要有成本、阻力、受益者与受损者 |

**全书终极问题**不是「朱元璋能不能当皇帝」，而是：他能否在建立王朝之后，建立一套超越他个人能力的治理机制？

## 第一卷 · 凤阳旧事

- **时间起点**：元后至元四年（1338）起，收束于至正四年（1344）灾年（年份 × 年龄决策见 [世界观](worldbuilding/)）
- **地点**：濠州钟离县乡村
- **卷核心**：生存、识人、合作与规则的萌芽

### 卷目标

1. 建立朱重八幼年的生活环境与家庭处境。
2. 让未来的伙伴自然登场。
3. 通过小事件表现主角的现代思维。
4. 展现贫困社会中人们的实际困难。
5. 逐步建立人物关系和早期信任。
6. 为离开乡村、进入寺庙和漂泊生活铺垫。
7. 让想法被现实检验，而不是只听主角讲道理。

本卷不急于建立组织、招募部下或实施宏大改革。

## 章节工作流（滚动窗口）

**分层原则**：五幕表是**施工图**，不是顶层设计。顶层（全书/卷级）保持一行流，细拆只发生在动笔前——后章必然被前章成稿改变，提前拆满必然返工。

每章四步，循环滚动：

| 步 | 做什么 | 落点 |
|---|---|---|
| 选 | 从章节池拍板下一章写什么（顺手分拣灵感池） | 本页 |
| 拆 | 为这一章出五幕表（起/承/转/合/结，每幕「内容 + 功能」两列），确认后挂到本页 | 「下一章分幕」区 |
| 写 | 正文成稿入库 | `volume-1/chapter-NN.md` |
| 归档 | 幕表移入每章归档文件，进度表补一行章末状态/钩子 | `volume-1/outlines/chNN.md` |

**一次只拆一章**：上一章成稿后才拆下一章，幕表永远贴着最新剧情。短章可将「结」并入「合」，不硬凑五幕。

**灵感处理**：用户随时口述灵感 → 原样落入 [灵感池](#灵感池未分拣)。具体的灵感（一个事件、一个场景）直接记一行；**抽象的灵感由 AI 按四问拆解（命题/载体/去处/铺垫）后随原话一起入池**——拆解只到「能进章节池」为止，不提前拆幕。选章时分拣落点：章级创意 → 章节池；人物 → [人物档案](characters.md)；设定/历史 → [世界观](worldbuilding.md)；影响在写的章 → 直接改当前幕表。

## 灵感池（未分拣）

用户随时口述灵感，先记原话。**具体的**（一个事件、一个场景）直接一行入池；**抽象的**（一种感觉、一个道理、一个主题）由 AI 拆解后随原话一起入池。拆解只回答四个问题，不提前拆幕：

| 问 | 回答什么 |
|---|---|
| 命题 | 这灵感本质上想说一件什么事（一句话） |
| 载体 | 什么具体事件/冲突装得下它：谁和谁、争什么、赌什么 |
| 去处 | 放哪个阶段哪一卷——对照 [四阶段](#全书四阶段) 核心命题与写作禁区；属于后期阶段的命题，只在前期间留一颗种子场景 |
| 铺垫 | 要不要跨章铺垫：种子 → 显形 → 检验 |

| 日期 | 灵感原话 | 拆解（命题/载体/去处/铺垫） | 落点 |
|---|---|---|---|

## 卷际衔接

第一卷以灾年与家庭危机收束（对齐至正四年史实锚点），主角离开乡村进入皇觉寺——第二阶段「寺庙与漂泊」开启。卷末章节动笔前需回查 [世界观·史实锚点](worldbuilding/#史实锚点)。
