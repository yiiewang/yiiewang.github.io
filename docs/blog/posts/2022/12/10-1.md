# 硬件数据采集：温度监控

在系统运维和硬件监控中，CPU 温度是一个重要的健康指标。本文介绍如何在不同操作系统中获取硬件温度数据。

<!-- more -->

## Windows 系统

### 获取 CPU 温度

以管理员身份启动 PowerShell，执行以下命令：

```powershell
$(((Get-CimInstance -Namespace root/WMI -ClassName MSAcpi_ThermalZoneTemperature)[0].CurrentTemperature - 2731.5) / 10)
```

!!! note "说明"
    该命令通过 WMI 接口读取温度数据，返回值的单位是摄氏度（°C）。
