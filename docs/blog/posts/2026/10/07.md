# 把《国富论》二三四章读成一套传动系统

上一篇笔记里，我把《国富论》第一章读成了一台引擎——分工把劳动生产力放大几百倍，那是财富增长的动力源。但引擎不会自己转，它要靠一套传动系统，才能把动力传到整个社会。

斯密紧接着写的第二、三、四章，讲的就是这套传动系统：交换是天性，是动力输入的入口（第二章）；市场范围限定了分工能走多深，是管住燃料的管路（第三章）；货币是让交换顺畅运转的润滑（第四章）。

这三章不是三个并列的话题，是一条因果链：天性启动交换，交换的规模受市场约束，货币再把交换的成本降下来。顺序本身就是论证——先有冲动，再有边界，最后解决边界内的摩擦。

上一篇我留下过一个缺口。框架盈利论说，搭好底座等人来循环就能收租，可冷启动要有人来。这三章正好回答了一半：为什么会有人来。答案落在第二章。

## 一、第二章：交换是人类天性

斯密说，人类有一种其他动物没有的倾向：互通有无、物物交换、相互交易。这不是谁设计出来的制度，是刻在行为里的天性。

斯密的证据很朴素，也很有画面感：没有谁见过两只狗公平地互换骨头。狗要得到另一只狗的骨头，只会靠抢或者讨；人不一样，人会谈判，会提出你给我这个、我给你那个的交换条件。交易需要双方理解对方的意图，并且自愿成交，这是人独有的事。

但斯密没有停在天性这一步。他接了一句关键的推论：一旦分工确立，每个人自己生产的东西只够满足自己需求的极小部分，剩下的大部分需求，都要靠交换别人的劳动产品来满足。

一句话概括：**在分工社会里，每个人在相当程度上都成了商人。**

这句话是把天性和第一章的分工接起来的那根轴。分工让人只做一件事，那他就必须靠交换拿回其余所有东西。交换不是分工的附带品，是分工能成立的前提。

## 二、第三章：天性为什么也有边界

交换是天性，但天性的成果受一个硬约束支配。斯密说，分工的程度受交换能力大小的支配——换句话说，**能交换出去的市场范围，限定了分工能做到多深。**

他没有讲抽象道理，而是给了一个很具体的场景：山谷里孤立的小村落，养不活一个专门做钉子的人，只能靠走村串巷的铁匠偶尔来做；在大城市里，同样一个铁匠，可以只靠做钉子过一辈子。原因不是城里人手更巧，而是城里的需求足够大、足够密，能让他只做一道工序还活得下去。

这里是承接上一篇的。前一章我提过制针厂——它只能开在城里，开在山村活不下来。这一章补上了那句伏笔的机制：不是制针的技术难，是山村的市场太小，撑不起十个工人各自专营一道工序。

### 2.1 水运：第一个市场半径的放大器

那市场范围靠什么扩大？斯密给的答案是水运。

同样一批货，走水路运到远方，成本远低于走陆路。原因很直白：一条船靠风力和人力，就能装载相当于几十辆、上百辆车的东西，而路上每辆车都要吃草料、要人照看、要过路。运力差几个量级，单位运输成本就差几个量级。

结论：水运便宜，所以沿海、沿河的地区天然拥有更大的市场半径，因而更早地发展出细致分工和富裕。斯密的观察是，地中海沿岸、大西洋沿岸的文明先富，不是风水好，是船到了。

我把这条规律命名为：**市场半径决定分工半径。**

| 变量 | 含义 | 斯密时代的载体 |
|------|------|--------------|
| 市场半径 | 一件产品能触达的有效需求范围 | 水路、航道、沿岸港口 |
| 分工半径 | 能养活多少专职分工环节 | 城市里的专职行业 |
| 因果关系 | 半径大，则分工可以更深 | 沿海先富、内陆滞后 |

## 三、第四章：货币怎么解决交换的堵点

交换有天性，市场有范围，但物物交换本身有一个死结。

斯密点出的是双重巧合难题：你想拿自己的东西换别人的东西，必须同时满足两个恰好——你要的正好是他有的，他想要的正好是你肯给的。两个恰好同时发生的概率很低，交换就卡住了。

解法是找一个中介物：一件人人都肯接受的东西，先用它把自己的货换出去，再用它去换自己真正要的东西。斯密列举的是不同时空里人们用过的媒介——牲畜、盐、贝壳，都是当地人人肯收的东西。

为什么最后是金属胜出？因为金属同时满足三个条件：可分割（想换多少切多少）、可保存（不会腐烂）、便携（体积小价值高）。在这三件事上，牲畜会死、盐会化、贝壳不方便切割。

金属的演化也分阶段。先是铜、铁这类贱金属，承担日常小额交易；随着事务变多、交易变细，银、金逐渐接管更小额、更精细的职能。斯密的落点是：**货币是演化的产物，不是谁发明的产物。** 没有哪一年突然诞生了货币，是一代代人用着用着，把最顺手的媒介筛了出来。

### 3.1 铸币：把信任外包出去的第一步

金属本身也有天然缺陷：每次交易都要称重量、验成色，既麻烦又容易被做手脚——有人掺假、有人磨边。

于是出现了铸币：在金属块上打一个官印，标明重量和成色。有了这个印记，交易双方不用再当场称、当场验，认印记就行。

铸币权的归属也经历了一次演化：最早是私人或商人自己打记号，证明自家银锭的分量；后来国家把铸币权收归垄断，印记变成公信力的象征。

我的观点：**这一步是货币史上第一次把信任外包。** 在此之前，信任需要交易双方当场建立——你得自己会称、会看、会防骗。铸币之后，信任被转移到一个第三方凭证上，交易双方只需要信任那个印记，不需要再信任彼此。信任的成本降下来，能一起做交易的范围就扩大了。

### 3.2 使用价值与交换价值：一个悬念

斯密在这部分最后，抛出了全书最核心的问题之一。他说，价值这个词有两个含义：一是使用价值，即这件东西能满足什么需要；二是交换价值，即这件东西能换到多少别的货。

他用一对极端例子说明了二者的背离：**使用价值极高的东西，交换价值往往极低；交换价值极高的东西，往往几乎没什么用处。** 水几乎不可或缺，却换不到什么；钻石没什么实际用途，却极其昂贵。

斯密由此提出了他后面要解决的任务——探明支配商品交换价值的法则。这就是价格成因的问题，也是后文劳动价值论的起点。这篇笔记到这里打住，把这个悬念留到下一篇。

## 四、我的观点一：交换是天生的流量入口

下面是我的读法，和斯密本人的论述分开说。

上一篇我讨论框架盈利论时，留下一个没答的问题：为什么搭好框架会有人来？这三章给了一半答案——因为交换是天性。

既然交换是天性，那么一件重要的事就成立：**流量不需要购买，只需要承接。**

人本来就要交换。城市、集市、港口、电商平台、支付网络，这些地方之所以天然有流量，不是因为它们创造了交换的欲望，而是因为它们恰好接住了人类本来就有的交换冲动。做框架的人要做的不是从零造需求，是站在需求必经的节点上。

这正好补上上一篇的缺口：框架的冷启动为什么可行？因为需求侧不是被创造出来的，是被承接的。你要解决的只是承接的效率，不是说服人们来交换。人们本来就要换，你只需要比别人接得更顺、更便宜、更可信。

## 五、我的观点二：把市场半径推到今天

斯密时代，市场半径的载体是水运。今天呢？拆开看，其实换了载体，没换结构。

| 维度 | 斯密时代 | 今天 |
|------|---------|------|
| 市场的物理边界 | 水运可达的沿岸与航道 | 物流网络覆盖到哪里 |
| 市场的信息边界 | 口耳相传、集市名气 | 互联网的触达与搜索 |
| 交易的结算边界 | 铸币流通的地域 | 支付清算网络 |
| 市场的隐性边界 | 语言、习俗、法规 | 语言、合规、平台规则 |
| 半径的放大器 | 船 | 物流 + 互联网 + 支付 |

几个世纪过去，结构没变：谁的半径大，谁能养活的专职分工就多。今天的创业者选址，本质上就是在选市场半径——你在哪个城市、接入哪个平台、面对哪批客户，决定了你能做到多深的分工、多细的产品。

由此我得到一个可执行的判断：**垂直市场（细分行业）的本质，是把一个小市场做到全国半径。** 选一个足够窄的切口，窄到没人愿意认真做，然后用今天的半径工具把它铺满全国甚至全球。小市场乘以大半径，等于深分工。这正是斯密笔下城里铁匠可以专做钉子的现代版本。

## 六、我的观点三：信任外包是一整条史

把铸币、国家垄断铸币权、现代金融，一直到区块链排成一条线，会看到同一件事反复发生：**每一步都是让信任的成本更低、信任的范围更大。**

- 以物易物：信任范围等于熟人，成本是每次当场验货。
- 金属称量：信任范围略大，成本是每次称重验色。
- 铸币：信任外包给印记，成本下降到只需认印记。
- 国家铸币权：信任集中到一个垄断主体，范围扩到全国。
- 银行与信用卡：信任外包给账本与机构网络。
- 区块链：信任外包给一套公开可验证的算法，范围扩到无需信任任何单一机构。

用 IF-THEN 写出来：

- IF 信任媒介的成本足够低，且信任范围足够大，THEN 陌生人之间可以放心交易。
- IF 陌生人能放心交易，THEN 大规模协作可行，交换规模扩大。
- IF 交换规模扩大，THEN 市场半径扩大，分工进一步深化——绕回第三章那条规律。

所以我的判断是：**区块链不是发明了一个新东西，是把斯密看到的那套演化推向下一节。** 铸币把信任外包给国家印记，区块链把信任外包给代码。变的只是外包对象的成本结构，不变的是那条主线——降低信任成本、扩大信任范围，让更大范围的分工得以发生。

## 七、总收：二三四章是一台完整的传动系统

把三章合起来看：第二章提供输入的入口（交换天性），第三章管住输入的规模（市场半径），第四章降低流通过程的摩擦（货币与信任）。天性负责启动，市场负责放大，货币负责润滑。三个缺一个，第一章那台引擎都传不出动力。

上一篇谈的是引擎，这一篇谈的是传动。下一篇，斯密要回到引擎内部，回答第四章留下的那个问题：交换价值到底由什么支配。那是劳动价值论的开场。
