证明图：为什么 P 挡不住 X（P1 入队序 = 创建序，P2 同一 TTL）

时间 →
        -------- P 创建 ---------------- X 创建 ---------------- X 过期(te) --- tick
          P 早于 X 入队：createdAt_P ≤ createdAt_X
          同一 TTL：expireAt_P ≤ expireAt_X = te

反证假设：tk 这轮结束时 X 仍在队列 → 有东西挡在 X 前面
唯一能挡路的形态：pending 里的 P（持有策略保证其余都已出队）
但 P 在队列里排在 X 前面（P1）且过期不晚于 te（P2）
expireAt_P ≤ te < tk → tk 轮开始前 P 已过期 → 该轮必然清掉/释放 P
矛盾！所以 X 要么 tk 轮被清，要么成为新的 pending
成为 pending 的 X：下一轮就是全队列最老的元素，同样必被清

结论：清理延迟 ≤ 一个 tick（Δ）
+----------------------+
| t_clean ∈ [te, te+Δ] |
+----------------------+
