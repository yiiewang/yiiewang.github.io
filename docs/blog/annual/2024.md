# 2024 年度集锦

> 上半年在修工具，下半年在写论文、看市场、造轮子。全年 26 篇，但下半年每篇都比上半年重。

## 卷首语

2024 有一条很清楚的分界线，就在九月。

九月之前写的是[Code Server 部署](../posts/2024/02/27-1.md)、[Shell 循环](../posts/2024/06/27.md)、
[GitLab CI/CD](../posts/2024/07/09.md)、[数位板配置](../posts/2024/08/11.md)——
全是"把一个东西装好、跑通"的活，写下来主要为了下次不用再查。

九月之后，A 股那波大涨把市场的注意力拽了过去，[爱在深秋](../posts/2024/10/02-1.md)是转折点。
紧接着是四篇软考论文，然后是十一、十二月那段最过瘾的：用 Go 造
[BitTorrent 客户端](../posts/2024/11/13.md)、[不到 100 行的容器](../posts/2024/11/23.md)、
[从零开始的数据库](../posts/2024/11/25.md)。

## 主线一：软考架构师论文四篇

十月到十一月，四篇论文一路写下来，题材都来自真实项目：

1. [论软件架构的选择](../posts/2024/10/02-2.md) — 移动信息化开放平台的三层分层架构
2. [论软件系统架构风格](../posts/2024/10/04.md) — 同上项目，讲设计与实施
3. [论软件的可靠性设计](../posts/2024/11/07.md) — 三维轻量化异构项目：容错、N 版本程序设计、冗余
4. [论面向对象设计](../posts/2024/11/09-1.md) — 同项目，RUP 统一过程模型

!!! tip "这四篇的读法"
    套路是固定的：项目背景 → 理论要点 → 实践落地 → 运行效果。
    想快速过一遍软考论文，看第三篇（可靠性设计）最划算。
