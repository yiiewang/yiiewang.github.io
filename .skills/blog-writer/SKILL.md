# Skill: blog-writer

> **目标**：让 AI 拿到一个**主题或素材**，就能快速写出符合 cloaks 个人站风格的博客，**直接落盘到 `docs/blog/posts/`**。

## 触发场景

用户说：
- "写一篇关于 X 的博客"
- "把这段经验/对话/资料写成文章"
- "起一个 XXX 的草稿"
- "博客的标题可以是 X，内容涵盖 A、B、C"

## 工作流（必读）

### 1. 确认关键信息

加载本文件后，**先问 3 个问题**（如果用户没指定）：

| 问题 | 默认值 |
|------|--------|
| 主题/方向 | 用户必给 |
| 目标读者 | "面向工程师（自己 + 同类人）" |
| 类型 | 技术 / 教程 / 复盘 / 札记 / 读书 |

### 2. 加载配套文件

按顺序读取：
1. `references/frontmatter-template.md` —— 写文件头
2. `references/writing-style-guide.md` —— 把握文风
3. `references/post-structure.md` —— 按类型选章节套路
4. `examples/` 下同类型的真实博客做参考

### 3. 生成大纲（必须先给大纲）

- 用 3-6 个二级标题
- 每个标题写一句话说明
- 让用户**确认或修改**后再开始写正文
- 例外：用户明确说"直接写"时跳过

### 4. 写正文

- 中文为主，技术名词保留英文
- 短段落（2-4 句），多用代码块
- 必须有 `<!-- more -->` 分隔符
- 代码块用 ` ```go ` 等带语言标签
- 标题里可以有 emoji（🟢🔧🧠 等），但要克制

### 5. 写入文件

- 路径：`docs/blog/posts/{YYYY}/{MM}/{DD}[-{n}].md`
- 日期默认取**今天**；询问用户确认
- 同一日期已存在 → 追加 `-1` / `-2` / `-3` 后缀
- 创建必要的子目录

### 6. 自检清单

完成后过一遍：
- [ ] frontmatter 6 个字段都有
- [ ] 第一段开门见山（不写"今天我们来聊聊..."）
- [ ] `<!-- more -->` 在合适位置（通常在前 1/3）
- [ ] 代码块带语言标签
- [ ] 章节标题有逻辑递进
- [ ] 有小结或结尾段落
- [ ] 关联的 internal 链接都用相对路径
- [ ] 加粗语法 `**text**` 前后有空格（`叫 **战略**` 而非 `叫**战略**`）

## 风格速查

> 完整版见 `references/writing-style-guide.md`

- **基调**：技术直男风，幽默犀利，少废话
- **段落**：短。**单段不超 4 句**。
- **代码**：能上代码就不解释
- **结构**：是什么 → 为什么 → 怎么做 → 注意事项
- **语气**：第二人称偶尔用，但不要"亲，你学会了吗"
- **引用**：论文 / 官方文档用链接或脚注；不抄大段
- **标题**：简洁有力，可带 emoji

## 类型适配

| 类型 | 套路 | 范例 |
|------|------|------|
| 技术 | 背景→原理→实现→坑 | `examples/tech-post.md`（PBFT） |
| 教程 | 目标→步骤→代码→扩展 | `examples/tutorial-post.md`（回文数） |
| 复盘 | 问题→排查→根因→解决→总结 | `examples/review-post.md`（幂等设计） |
| 札记 | 观点→论据→延伸思考 | `references/post-structure.md` 第四节 |
| 读书笔记 | 书籍信息→核心观点→摘录→思考 | `references/post-structure.md` 第五节 |

## 注意事项

- **不要编造事实**：不确定的内容写"待确认"或"参考官方文档"
- **不要复制用户提供的整段内容**作为正文 —— 改写、提炼、重组
- **不要在小博客里写大章节**：2000 字以内为佳
- **不要用空话开头**："在现代软件开发中..." / "随着 XXX 的发展..." 这类删掉
- **关联的 blog 引用**：用 `/blog/posts/YYYY/MM/DD/` 形式

## 完成标志

- 文件已创建在 `docs/blog/posts/YYYY/MM/DD[-n].md`
- frontmatter 完整
- 大纲已得到用户确认
- 自检清单全部通过
- 向用户报告：文件路径 + 一句话简介 + 三个候选标题（如有备选）
