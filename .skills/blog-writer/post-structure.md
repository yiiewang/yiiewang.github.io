# 章节结构模板

> AI 根据博客类型选择对应模板。

## 一、技术原理类

**适用**：讲解一个算法、协议、设计模式、底层原理

```markdown
# {技术名}

{第一段：一句话说清是什么 + 解决什么问题。1-2 句。}

<!-- more -->

## 背景

{为什么需要这个技术？解决了什么痛点？之前的方案有什么问题？2-3 段。}

## 核心内容

### {核心概念 1}

{概念阐述 + 关键公式/图示。}

### {核心概念 2}

{继续展开。}

### {核心概念 3}

{收束，给出整体理解。}

## 示例

{一个能跑通的最小示例。可选。}

```go
// 代码
```

## 注意事项

- ⚠️ ...
- ✅ 推荐做法

## 小结

{一段话总结：本质是什么 / 适用场景 / 局限性。}
```

**范例**：[`examples/tech-post.md`](./examples/tech-post.md)（PBFT）

## 二、教程类

**适用**：手把手教读者做某事、某个工具用法、某段代码怎么写

```markdown
# {目标动词 + 对象}：{副标题}

{第一段：说明目标和适用读者。}

<!-- more -->

## 目标

{最终效果是什么？读完后能做什么？1 段。}

## 思路

{整体方案和关键步骤预览。}

## 实现

### 步骤 1：{...}

{详细步骤 + 代码。}

### 步骤 2：{...}

{继续。}

### 步骤 3：{...}

{继续。}

## 完整代码

{把全流程代码整合。}

## 扩展

{进一步的优化方向、可替换方案。}

## 小结

{回顾关键步骤 + 适用场景。}
```

**范例**：[`examples/tutorial-post.md`](./examples/tutorial-post.md)（回文数）

## 三、复盘类

**适用**：线上事故、踩坑记录、项目总结

```markdown
# {一句话描述事故或挑战}

## 引子

{故事开头：真实场景、痛点共鸣。1-2 段。}

<!-- more -->

## 问题

{把问题说具体。最好列出"症状 1 / 2 / 3"。}

## 背景

{为什么会这样？表层 vs 本质。}

## 解决

### 思路 1：{...}

{分析 + 代码。}

### 思路 2：{...}

{继续。}

### 思路 3：{...}

{继续。}

## 落地

{完整方案 / 数据模型 / 配置示例。}

## 注意事项

{边界条件、可能引入的新问题。}

## 小结

{升华到方法论：这类问题的通用解法。}
```

**范例**：[`examples/review-post.md`](./examples/review-post.md)（幂等设计）

## 四、札记类

**适用**：短篇想法、灵感、问题记录（500-1500 字）

```markdown
# {短标题}

{开门见山。1-2 段。}

<!-- more -->

## 现象 / 问题

{精简描述。}

## 思考

{你的分析过程。}

## 验证

{试验或代码佐证。}

## 结论

{一句话。}
```

## 五、读书笔记类

```markdown
# 《{书名}》读书笔记

## 写在前面

{为什么读这本书 / 整体评价。}

<!-- more -->

## 核心观点

### 观点 1：{...}

{复述 + 你的理解。}

### 观点 2：{...}

{继续。}

### 观点 3：{...}

{继续。}

## 行动建议

{读完之后的实践清单。}

## 推荐指数

{⭐⭐⭐⭐⭐ + 一句话理由。}
```
